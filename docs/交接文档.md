## 一句话

`/polish` 是一个 DSH 插件：把粗糙提示词转写成规范提示词，确认后写进输入框（**不自动发送**）。功能已实现并在真实 GUI 中跑通；62 项自动化测试全绿。**盲读测试（人工验收）尚未执行**。

入口页只做路由。事实的唯一出处在下面这些类型文档与 [AGENTS.md](../AGENTS.md) 的规则。

## 最短上手路径

1. 读 [AGENTS.md](../AGENTS.md) 的规则块（8 条，含「临时文件只放 `tmp/`」「每完成一个业务就 commit」）。
2. 跑 `npm test`（零依赖，Node 内置 `node:test`），确认 62 项全绿——这是当前基线。
3. 想改行为：先读 [architecture.md](architecture.md) + [data-model.md](data-model.md)；改完按规则 D4 补测试。
4. 改了 `index.js`（Host）：按 [runbook.md](runbook.md) §Host 改动必须重启 走——**先探针，再重启**；改了 `client.js` 只需硬刷新页面。
5. 收尾按 [testing.md](testing.md) 跑盲读测试（3 类粗糙输入 × 新会话只发规范版）。
